# 🛡️ Curso Interactivo: Competencias Digitales y Seguridad en Internet

Ambiente de aprendizaje inmersivo tipo **SENA** (formación complementaria virtual), desarrollado como página web navegable. Cumple con los requisitos de la guía de la Unidad 3 (Universidad de San Buenaventura): espacio de bienvenida, ruta de aprendizaje, estaciones, recursos digitales, actividades interactivas y evaluación.

## 🎯 Contenido

| Estación | Tipo |
|----------|------|
| 🏠 Bienvenida | Presentación y propósito |
| 📋 El programa | Competencia + Resultados de Aprendizaje (RAP) |
| 💻 Módulo 1 | Competencias digitales (DigComp) + video |
| 🔑 Módulo 2 | Contraseñas seguras y 2FA |
| 🧪 Actividad | Verificador de contraseñas en tiempo real |
| 🎣 Módulo 3 | Phishing, fraudes y malware + video |
| 🕵️ Actividad | Simulador: detecta el phishing |
| 🌐 Módulo 4 | Privacidad y huella digital |
| ✅ Evaluación | Quiz final autocalificable (6 preguntas) |
| 📊 Rúbrica | Criterios de evaluación y lista de chequeo |
| 🎓 Cierre | Reflexión final |

## 🚀 Cómo verlo

Al ser HTML/CSS/JS puro, solo necesitas abrir `index.html` en un navegador.

Para probarlo con un servidor local:

```bash
python3 -m http.server 8000
# luego abre http://localhost:8000
```

## 🌍 Publicar con enlace público (GitHub Pages)

1. Sube estos archivos a un repositorio de GitHub.
2. Ve a **Settings → Pages**.
3. En *Source* elige la rama `main` y carpeta `/ (root)`.
4. GitHub te dará un enlace público del tipo `https://usuario.github.io/repositorio/`.

Ese enlace es el que se entrega en la actividad.

## 🛠️ Tecnologías

- HTML5, CSS3 (diseño responsive, identidad visual verde tipo SENA)
- JavaScript puro (sin dependencias ni frameworks)

## ✨ Características interactivas

- Navegación por estaciones con menú lateral y botones Anterior/Siguiente
- Barra de progreso que registra las estaciones visitadas
- Verificador de contraseñas con medidor de fuerza en vivo
- Simulador de phishing con pistas interactivas
- Quiz final autocalificable con retroalimentación
- Navegación con teclado (flechas ← →)
